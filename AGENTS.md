# AGENTS.md

This repo is a collection of Agent Skills for personal finance, jobs, crypto and content creators, organised by country. Each skill is a folder with a `SKILL.md` under `plugins/<plugin>/skills/<skill>/`. Country skills are prefixed with the country (`india-`, `canada-`, `us-`).

When a user's request matches a skill's description and their country, read that `SKILL.md` and follow it. Use the calculator script (or the code embedded at the end of the SKILL.md) for every number; don't do tax arithmetic by hand.
